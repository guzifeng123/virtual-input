# IDE 光标自动输入（virtual-input）

Windows 桌面工具：选择一个 TXT 文件后，把内容通过 Win32 `SendInput` 以**真实键盘事件**的方式逐字符发送到当前光标位置，适用于网页代码框、VS Code 等 IDE 或任意可输入窗口。

- **不使用剪贴板**：不读取、也不写入系统剪贴板。
- **不读取目标内容**：不访问网页 DOM，也不读取编辑器缓冲区。
- **零第三方运行依赖**：仅使用 Python 标准库（`ctypes` + Tkinter）。

## 功能特性

- 逐字符 Unicode 输入，支持中文、emoji 以及 BMP 以外字符（自动按 UTF-16 代理对发送）。
- 拟人化随机节奏：字符间隔随机，空格 / 回车 / Tab 与结构符号可设置额外延迟。
- 三种编辑器预设：**VS Code**、**通用 IDE**、**纯文本**。
- 代码上下文感知的输入规划：区分代码、字符串与注释，正确处理编辑器自动闭合括号 / 引号，并在结束时清理多余的自动闭合符。
- 平台校准流程：发送固定 C++ 样本 → 回传比对 → 生成平台策略配置。
- 全局快捷键：**F8** 暂停 / 继续、**F9** 停止；前台窗口切换时自动暂停。
- 多编码自动识别：UTF-8 BOM、UTF-8、GBK、Windows 当前 ANSI（mbcs）；统一 CRLF / CR / LF 换行。
- 实时进度与预计输入时间显示。

## 工作原理

1. 读取并解码所选 TXT 文件，把换行统一为 `\n`。
2. `iter_text_actions` 对文本做轻量词法分析（行 / 块注释、转义字符串、普通括号），把源字符规划为一系列动作：
   - 普通字符：以 `KEYEVENTF_UNICODE` 发送；
   - 换行 / Tab：发送真实的 **Enter** / **Tab** 虚拟键；
   - IDE 模式下符合规律的源缩进：跳过，交给编辑器自动缩进；
   - 编辑器已自动生成的闭合符：不再重复输入，改为按 **→** 越过；
   - 输入结束时：用 `Ctrl+Shift+End` 选中并删除残留的自动闭合符。
3. 每个动作之间按设定的随机间隔等待，可随时暂停或停止。

> 规划器只处理与键盘输入相关的语法结构，并非完整的编程语言解析器，也不校验目标文本。

## 环境要求

- Windows（仅支持 Win32）。
- Python **3.10+**，安装时勾选 Tkinter（官方安装包默认包含）。
- 双击 `start.cmd` 运行需要 **PowerShell 7**（`pwsh`）；也可以直接用 Python 运行，无需 PowerShell。
- 无第三方 Python 运行依赖。

## 运行

方式一：双击 `start.cmd`，或在 PowerShell 中执行：

```powershell
.\start.ps1
```

方式二：直接运行主程序：

```powershell
python main.py
```

## 使用步骤

1. 点击 **浏览文件** 选择要输入的 TXT 文件（或先生成校准样本）。
2. 根据需要调整倒计时、字符间隔、额外延迟和编辑器预设。
3. 点击 **开始输入**，在倒计时结束前切换到目标窗口，并把光标点到目标输入位置。
4. 输入过程中可用 F8 暂停 / 继续、F9 停止。

默认参数：倒计时 **3 秒**；字符间隔在 **0.03–0.08 秒**间随机；空格 / 回车 / Tab 额外延迟 **0.12 秒**；`{}`、`[]` 等结构符号额外延迟 **0.25 秒**。这些数值均可在界面中修改。

停止会保留已输入内容，下次点击 **开始输入** 仍从文件开头重新发送。关闭程序会停止后台线程并注销全局快捷键。

## 编辑器预设与 VS Code 配置

- **VS Code（默认）**：按代码、字符串和注释分别处理括号，不会把注释 / 字符串中的 `{}` 误判为自动闭合；编辑器已生成的闭合符通过移动光标越过，而不是重复输入。
- **通用 IDE**：跳过后续行中符合常见 2 / 4 / 8 空格或 Tab 规律的源缩进，把缩进交给编辑器；非标准缩进会原样保留，避免误伤特殊源码。
- **纯文本**：不做任何缩进或闭合符处理，逐字符完整发送。

为避免 VS Code 在输入时自动改写文本，建议先关闭自动配对、自动缩进、键入 / 保存格式化、回车接受建议、Tab 补全和内联建议。`vscode-input-settings.json` 提供了 C++ 的设置示例，可合并到 VS Code 用户设置 JSON：

```json
{
    "[cpp]": {
        "editor.autoClosingBrackets": "never",
        "editor.autoClosingQuotes": "never",
        "editor.autoIndent": "none",
        "editor.formatOnType": false,
        "editor.acceptSuggestionOnEnter": "off"
    }
}
```

合并后，右下角语言模式需选择 **C++**，工作区或配置文件的覆盖设置也要保持一致。其他语言可把示例中的 `[cpp]` 改为对应语言标识；若某个扩展仍改写文本，需要在目标工作区停用该扩展。

## 平台校准

当目标网页 / 编辑器会自动缩进或自动补全时，可用校准流程测量其改写行为：

1. 点击 **生成平台校准样本**，程序会写入 `平台校准样本.txt` 并自动选中。
2. 点击 **开始输入**，把样本发送到目标代码框。
3. 把目标框中的最终内容复制出来、另存为一个 TXT 文件。
4. 点击 **分析网页回传结果**，选择该 TXT，程序会与原始样本逐行 diff：
   - 完全一致：保存“原样输入”策略，不启用任何补偿；
   - 存在改写：把观察到的缩进规律写入 `平台自适应配置.json`，供后续输入参考。

校准不会根据“丢失 / 被替换的字符”自动推断闭合符补偿，因为在纯文本回传中，丢失的源字符与编辑器自动生成的闭合符无法区分，盲目补偿会让下一次输入再次丢字。需要闭合符补偿时，请在界面的“自动闭合符”字段中显式填写（如 `}])"`），该策略只在代码上下文生效。

## 快捷键

| 快捷键 | 功能 |
| --- | --- |
| F8 | 暂停 / 继续（继续后会重新倒计时） |
| F9 | 停止 |

- 倒计时结束、焦点仍停留在本工具上时，会自动暂停，等待你定位目标窗口后按 F8 继续。
- 前台窗口（顶层窗口）发生切换时自动暂停；同一窗口内切换标签页或输入框无法检测，操作前请先手动暂停。
- 若快捷键被其他程序占用，界面会提示，此时可改用界面按钮。

## 打包为可执行文件

项目使用 PyInstaller 打包（需先 `pip install pyinstaller`），三个 `.spec` 文件分别对应 V1 / V2 / V3：

```powershell
pyinstaller "屏幕自动输入-V3-平台校准.spec"
```

生成的 exe 位于 `dist/`，中间文件位于 `build/`，这两个目录均已在 `.gitignore` 中忽略。

## 测试

```powershell
python -m unittest discover -s tests -v
```

测试覆盖编码识别、Win32 `INPUT` 结构布局、Unicode / 换行映射、随机延迟、暂停与停止逻辑、IDE 缩进与自动闭合符规划，以及 VS Code C++ 样本回归。测试通过替换键盘发送函数实现，**不会**向当前窗口真实输入内容。

## 限制与注意事项

- “输入发送完成”仅表示键盘事件已发出，程序不回读目标内容，因此不做逐字比对结果校验。
- 换行和 Tab 是真实按键：网页可能将其解释为提交表单或移动焦点，单行输入框也无法保留多行文本。首次使用请先用短文本验证。
- 系统键盘事件无法绕过网页自身的输入限制；当目标程序以更高权限运行（如管理员窗口）时，发送可能失败，此时需以相应权限启动本工具。
- 无 BOM 文件的编码识别存在歧义，若出现乱码，请把文件另存为 UTF-8（推荐带 BOM）。
