# 网页光标自动输入

Windows 桌面工具：选择 TXT 文件后，将内容通过 Windows `SendInput` 逐字符发送到当前光标位置。程序不使用剪贴板。

## 运行

安装 Python 3.10+（包含 Tkinter）和 PowerShell 7 后，双击 `start.cmd`，或在 PowerShell 中执行：

```powershell
.\start.ps1
```

无第三方 Python 依赖。也可直接执行 `python main.py`。

点击“开始”后，在倒计时结束前切换到浏览器，并把光标放到目标输入位置。默认倒计时 3 秒，每个字符的延迟会在 0.03–0.08 秒范围内动态随机；空格、回车和 Tab 默认额外延迟 0.12 秒。输入界面可以手动修改最小/最大间隔和特殊字符额外延迟。

界面默认开启“IDE 代码模式”。代码模式会在每次回车后跳过源码下一行行首已有的空格/Tab，让 VS Code、Visual Studio、Dev-C++ 等 IDE 的自动缩进功能负责对齐，避免缩进重复。输入普通文本时可以关闭此模式；关闭后会完整保留文件中的行首空格。

界面会根据当前文件、最小/最大间隔、空格/回车额外延迟、结构符号额外延迟和 IDE 模式显示预计输入时间。预计值按随机区间的平均延迟计算，并同时显示包含倒计时的总耗时；实际时间会因系统调度和 IDE 响应略有变化。

`{ } [ ] < >` 默认额外延迟 0.25 秒，帮助 IDE 完成括号配对、自动缩进和补全。新增“IDE 自动补全后跳过的闭合符号”设置，默认留空以保证 `{}`、`{};` 等 TXT 原文完整输入；只有确认当前 IDE 会自动补全对应符号时，才填写例如 `}])>`，程序才会跳过源码中对应的闭合符号。可以只填写某一个符号，也可以随时清空。输入结束后会显示键盘事件校验结果，确认程序实际成功发送的逻辑字符数与预期一致。程序不会读取 IDE 内容，因此不能验证编辑器最终文本是否被其他插件改写。

使用 F8 暂停/继续、F9 停止，无需离开网页；也可使用界面按钮。继续会重新倒计时，请及时切回目标输入框。前台窗口发生切换时自动暂停；同一浏览器窗口内切换标签或输入框无法检测，操作前请先暂停。倒计时为 0 且焦点仍在工具上时，会暂停等待定位网页。

停止保留已输入内容，下次点击“开始”从文件开头重新输入。关闭程序会停止后台任务并释放快捷键。若快捷键被其他应用占用，界面会提示。

支持依次尝试 UTF-8 BOM、UTF-8、GBK、Windows 当前 ANSI 编码；无法解码时显示错误。无 BOM 的编码识别存在歧义，遇到乱码可将文件另存为 UTF-8。支持中文和 emoji；统一 CRLF/CR/LF 换行。

换行和 Tab 会转换为真实 Enter、Tab 按键：网页可能将其解释为提交表单或移动焦点，单行输入框也无法保留多行文本。请先用短文本在目标网页试用。系统键盘事件无法绕过网页本身的输入限制，目标程序权限高于本工具时可能发送失败。程序不读取或写入剪贴板，也不读取网页 DOM。

## 验证

运行 `python -m unittest discover -s tests -v` 检查编码、Win32 结构布局、Unicode/换行映射、暂停和停止逻辑。测试替换键盘发送函数，不向当前窗口输入内容。
